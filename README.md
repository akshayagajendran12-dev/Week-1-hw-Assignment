# Week-1-hw-Assignment
Java Programming Practice – Week 1
1. BMI Calculator for a Team

File Name: BMICalculator.java

Algorithm
Start.
Initialize arrays to store the heights and weights of 10 people.
Create a method getBmiStatus(double bmi) to classify BMI.
If BMI is less than 18.5, classify it as Underweight.
If BMI is between 18.5 and 24.9, classify it as Normal.
If BMI is between 25 and 29.9, classify it as Overweight.
If BMI is 30 or greater, classify it as Obese.
Calculate BMI using the formula: BMI = Weight / (Height × Height).
Display each person's height, weight, BMI, and health status in a formatted table.
Stop.
2. First Non-Repeating Character

File Name: FirstNonRepeatingCharacter.java

Algorithm
Start.
Read a word or sentence from the user.
Initialize a frequency array to count character occurrences.
Traverse the string and count the frequency of each character.
Traverse the string again from left to right.
Check whether each character has a frequency of 1.
If a character has a frequency of 1, display it as the first non-repeating character.
If no such character exists, display "No Non-Repeating Character Found".
Stop.
3. Reverse Customer Name

File Name: ReverseCustomerName.java

Algorithm
Start.
Read the customer's name from the user.
Initialize an empty string named reversedName.
Traverse the original name from the last character to the first character.
Append each character to reversedName.
Display the original customer name.
Display the reversed customer name.
Stop.
